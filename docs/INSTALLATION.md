# Instalación en HOT 40i · Android 13

Si ya tiene alpha02, instalar este APK encima: conserva paquete/firma y preferencias; no desinstalar. Las indicaciones sobre la alfa antigua solo corresponden a alpha01.debug.

1. Descargar `iPhoneDialer-FotoContacto-alpha03.apk`. No abrir el ZIP de fuentes para instalar; AAB tampoco se instala directamente.
2. Para evitar confundir dos apps con el mismo nombre, volver primero al Teléfono original desde Ajustes → aplicaciones predeterminadas → Teléfono. Cuando no haya una llamada activa, puede desinstalar la alfa antigua. Esto elimina sus preferencias/teclas rápidas locales, no por sí mismo los contactos/historial del proveedor del sistema. No es obligatorio desinstalar: los paquetes son distintos.
3. Abrir el APK desde Descargas/Archivos y confirmar instalación. Si Android pide permiso para instalar desde esa fuente, concederlo solo a la aplicación usada para abrir este archivo y revocarlo después. No desactivar Play Protect ni otras protecciones; si aparece un bloqueo de seguridad, informar del mensaje exacto.
4. Al terminar, pulsar Abrir para entrar inequívocamente en la instalación nueva. Su ficha de aplicación debe indicar 1.0.0-alpha03. Solicitar el rol de teléfono desde su botón y aceptar únicamente los permisos necesarios. Si conserva la antigua, las dos pueden mostrar el mismo nombre: puede desinstalar la alfa vieja para evitar ambigüedad.
5. Probar con un número conocido y no crítico: saliente, entrante, responder y finalizar. No usar números de emergencia para probar. Mantener disponible el Teléfono original.
6. Si vuelve a cerrarse: volver al marcador original; abrir Configuración de la nueva app y compartir voluntariamente el informe técnico. No incluye mensajes de excepción ni datos de llamadas. Un ANR o cierre forzado del fabricante puede no dejar informe.

Esta alfa NO está verificada todavía en el HOT 40i. La firma y compilación correctas no prueban llamadas reales.

## Descargar respaldos de firma
Guardar los archivos confidenciales de firma en almacenamiento personal seguro. El documento de recuperación contiene secretos y debe guardarse separado del 7z. No compartirlos en chats públicos ni añadirlos a Git. Sin esa misma clave no habrá actualizaciones compatibles. Ver SIGNING.md.
